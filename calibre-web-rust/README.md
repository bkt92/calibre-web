# Calibre-Web Rust Rewrite

A high-performance eBook library manager in Rust.

## Status

⚠️ **UNDER DEVELOPMENT** - This is an active rewrite.

## Quick Start

```bash
# Copy environment file
cp .env.example .env

# Edit .env with your configuration

# Run
cargo run
```

## Development

```bash
# Run tests
cargo test

# Run with logging
RUST_LOG=debug cargo run
```
